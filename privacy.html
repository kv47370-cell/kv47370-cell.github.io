KingV studio

Privacy policy

Effective 4 November 2026

KingV studio ("the app") is a private desktop tool used by the owner of the YouTube channel KingV the Traveller to publish and manage that channel. This policy explains what Google user data the app accesses, how it is used, stored and protected, and how access can be removed.

Who uses the app

Only the channel owner. The app has no other users and no public sign-up. It acts on one YouTube channel: the owner's own.

What the app accesses

When the owner signs in with Google, the app asks for these permissions, and uses each only for the purpose shown:

  • Manage your YouTube videos (youtube.upload): to upload the channel's videos and Shorts.
  • See, edit and permanently delete your YouTube videos, ratings, comments and captions (youtube.force-ssl): to set titles, descriptions, thumbnails, captions, playlists, schedules and the channel trailer, and to reply to comments on the channel's own videos. The app never deletes videos.
  • View YouTube Analytics reports for your YouTube content (yt-analytics.readonly): to read the channel's own views, watch time, subscribers and traffic sources for a weekly review.

The app does not access Gmail, Google Drive, contacts, location or any other Google data, and it does not access anyone else's channel.

How the data is used

Google user data is used only to provide the features above to the channel owner. It is not used for advertising, it is not sold, and it is not used to build profiles of viewers. The app sees viewer comments only as they appear on the channel's own videos, and only to read and answer them.

Storage and security

The app keeps its Google sign-in tokens in a private folder on the owner's computer, and saves the weekly analytics reports as files on the same computer. Nothing is stored on any server run by the app. The app itself sends data only to Google, over encrypted connections, when it calls the YouTube APIs.

Sharing

The app never sells Google user data, and apart from the AI assistant described here it does not share it with anyone. The owner runs the app with the help of an AI assistant (Claude, made by Anthropic): the assistant reads the app's results, such as an analytics summary, through Anthropic's service, only to carry out the owner's own instructions about the owner's own channel. The app does not use Google user data to develop, improve or train AI models.

Google API Services User Data Policy

KingV studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

KingV studio uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Keeping and deleting data

Sign-in tokens are kept until access is removed. Analytics reports are kept on the owner's computer for the channel's own records and can be deleted at any time. To remove the app's access to a Google account, open Google's third-party connections page or the security settings permissions page and remove KingV studio. The app then can no longer reach the account, and its stored tokens stop working.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
