KingV studio

The private publishing tool behind the YouTube channel KingV the Traveller, where King V travels back to the moments history still argues about.

What it does

KingV studio is a small desktop program that runs on the channel owner's own computer. With the owner's permission, it uses the YouTube Data API and the YouTube Analytics API to:

  • upload the channel's videos and Shorts and schedule when they go public;
  • set their titles, descriptions, thumbnails, captions and playlists;
  • set the channel trailer and the channel's banner and description;
  • reply to comments on the channel's own videos;
  • read the channel's own YouTube Analytics reports, such as views and watch time, for a weekly review.

Who can use it

Only the owner of KingV the Traveller. There is no sign-up and no other users. The program works on one YouTube channel: the owner's own.

Your data

KingV studio reads and changes only the owner's own YouTube channel, keeps what it needs on the owner's computer, and never sells or shares it. The privacy policy sets out exactly what it accesses, why, and how to remove that access.
